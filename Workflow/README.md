# Galaxy Workflows

Galaxy workflows used in the 2026 MSK Tn-seq Workshop.

| Workshop Part | Workflow | Description |
|---|---|---|
| Part 2 | `Part2_TnSeq_FASTQ_to_TRANSIT_Input.ga` | FASTQ processing, genome mapping, TA-site read counting, and generation of TRANSIT input files |
| Part 3 | `Part3_TRANSIT_Analysis.ga` | Gumbel essentiality analysis and Resampling-based differential fitness analysis |
| Part 4 | `Part4_TnSeq_Circos_Visualization.ga` | Genome-wide visualization of TA-site read counts and TRANSIT Resampling results |

Part 1 covers the principles of Tn-seq and library construction and does not require a Galaxy workflow.
